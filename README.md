## 🚀 Featured Project

### 🔍 AI Resume Analyzer
An AI-powered web application that analyzes resumes, provides ATS scores, and gives personalized feedback based on job listings.

**Key Features**
- Client-side authentication (no backend)
- Resume upload & storage
- AI-powered resume matching
- ATS score & feedback
- Modern, reusable UI components
- Fully responsive design

**Tech Used**
- React
- React Router
- Tailwind CSS
- Puter.js
- Vite
- Zustand
